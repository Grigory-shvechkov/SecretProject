# Everything Vision/detection.py's FishDetector (ultralytics YOLO) needs,
# for installing all at once instead of hitting one ImportError at a time.
#
# Install with dependency resolution turned OFF:
#     pip install --no-deps -r requirements-ml.txt
#
# NOT `pip install -r requirements-ml.txt` -- without --no-deps, pip
# tries to resolve every package below against each other AND against
# opencv/numpy, which is exactly what sent plain `pip install ultralytics`
# into a multi-minute backtracking search through old releases (see
# requirements.txt). --no-deps installs exactly what's listed here, no
# resolution, no backtracking.
#
# This list is what `python3 -c "from ultralytics import YOLO"` has
# actually been observed to need on this Pi (Python 3.9, piwheels) --
# found by installing ultralytics --no-deps and resolving each
# ImportError by hand. Ultralytics doesn't publish a stable "just these,
# no opencv" dependency list, so a future ultralytics version may need
# something not listed here yet: re-run the import check above, and add
# whatever it names to this file.
ultralytics
torch
torchvision
pyyaml
pillow
tqdm
matplotlib
pandas
psutil
py-cpuinfo
scipy
ultralytics-thop
