# Fish detection runs on TensorFlow Lite, not PyTorch/ultralytics.
# PyTorch was tried first and is a dead end on this hardware: official
# PyTorch has never published wheels for 32-bit ARM (armv7l), at any
# version, on PyPI or piwheels.
#
# tflite-runtime 2.14.0 does publish an official cp39-armv7l wheel on
# PyPI, which is why it's pinned to that exact version here rather than
# left open -- an unpinned version could resolve to a future release
# without an armv7l wheel and send pip into the same backtracking search
# that plain `ultralytics` triggered.
#
# One remaining risk, unconfirmed as of this file: that wheel's platform
# tag is manylinux_2_34, which needs glibc >=2.34 (Debian Bookworm+). If
# this Pi is still on Bullseye (glibc 2.31), pip will reject it as
# incompatible even though the Python version/architecture match. If
# that happens: either upgrade this Pi to Bookworm, or fall back to
# onnxruntime (see github.com/nknytk/built-onnxruntime-for-raspberrypi-linux
# for an armv7l-compatible build) instead of tflite-runtime.
tflite-runtime==2.14.0
